# 간격 기준과 전수 검사 (2026-10-20 확정)

배포 제외 문서. 기준은 사용자가 정한 값이고 "의도된 예외"는 없다. 예외가 필요하면 목록으로 보고하고 승인 후에만 둔다.
측정기: `design/tools/spacing_audit.py` (실제 크롬, 390·1280, 기준값 ±4px, 64px 초과는 무조건 실패).

## 기준 (tokens.css)

| 구분 | 토큰 | 모바일 | 데스크톱(1024+) |
|---|---|---|---|
| 섹션 사이 (블록 끝 → 다음 섹션 제목) | --gap-section (= --space-section) | 40 | 48 |
| 섹션 제목 → 내용 | --gap-title | 12 | 16 |
| 소제목(h3) 위 | --gap-h3-top | 24 | 32 |
| 소제목(h3) 아래 | --gap-h3-bottom | 8 | 12 |
| 카드 사이 | --gap-card | 12 | 16 |
| 카드 안 여백 | --pad-card (= --space-card) | 20 | 24 |
| 문단 사이 | --gap-para | 12 | 12 |
| 페이지·허브 제목(h1) 머리 → 첫 섹션 | --gap-h1 | 24 | 32 |
| 섹션 제목 글꼴 | --fs-section / --fw-section | 18 / 700 | 20 / 700 |

`--space-section`은 데스크톱 64 → 48로 바뀌었다(섹션 사이 기준).

## 검사 방법

- 섹션 제목 = main 안 h2, .hub-section-label, .ds-blog-h, .ds-col-title, .sibling-title: 글꼴이 H 토큰과 같은지, 바로 위 블록과의 간격(섹션 사이), 바로 아래 내용과의 간격(제목→내용).
- 소제목 = 글·설명 흐름 안 h3: 위(앞 문단·목록·표)와 아래.
- 카드 = 둥근 상자(바탕·테두리·그림자): 이웃 카드 사이(세로·가로), 안쪽 여백(위·왼쪽, 목록 카드는 좌우).
- 문단 = 이웃한 p. 64 초과 = main 안 위아래로 이웃한 모든 블록.
- "보이는 간격": 바탕·테두리·그림자가 없는 블록의 안쪽 여백은 간격에 넣는다. 위 블록은 화면상 바로 위에 그려진 것(모바일 order·display:contents와 무관), sticky 목차는 제자리 블록으로 센다.
- 판정에서 빼는 것: 페이지 제목(h1·허브 제목) → 첫 섹션(64 초과만 검사), 섹션 제목 바로 아래 하위 제목(제목→내용 규칙이 잰다), 광고 칸 안쪽(이웃 블록으로는 센다), 시트·펼침 메뉴·결과 바, 입력 컨트롤(입력칸·선택 버튼·탭).
- 대상: 홈(최근 기록 0개·3개), 허브 12, 계산기 102 + dti·pyeong(11/9까지 main 판, 승인된 예외), 블로그 목록, 글 20편(전체에서 고르게), 정보 페이지 5, 404, /recent/.

## 원인과 공용 수정 (base.css 끝 "간격 정리" 블록, 토큰만 사용)

1. 섹션 제목 글꼴이 제각각(계산기 하단 "다른 ○○ 계산기"·"관련 가이드" 14px/600, 허브 지식 24px, 날짜·건강 계산기 seo-card 16~18px/800~900) → 전부 --fs-section/--fw-section.
2. 계산기 하단 목록이 앞 블록(신뢰 정보 카드 등)에 0~14px로 붙음 → 섹션 사이.
3. 계산기 칸(입력·결과·이어서 계산) 사이 20px, "이어서 계산 → 관련 계산기" 20px → 섹션 사이.
4. 허브 그룹·지식 블록 사이 12~20px, 허브 지식 섹션 제목의 em 여백, 비어 있는 옛 허브 칸이 흐름 gap을 두 번 만듦 → 섹션 사이, 숨김.
5. sticky 목차 다음 섹션이 목차 안 여백만큼 더 벌어짐, main 바로 아래 광고 앞뒤 0px → 섹션 사이.
6. 소제목 위 20px(데스크톱 32 필요), 4대보험 인라인 h3 구분선(padding-top 16 + border) → 소제목 토큰, 섹션 제목 바로 아래 h3는 위 0.
7. 카드 안 여백 12~16px(입력 카드, 이어서 계산 카드, 결과·기준·검토·안내 상자, 글 안 강조·사례·CTA 상자, 홈 시즌 카드, 블로그 대표·사이드 상자, 정보 페이지 상자 등) → --pad-card. 목록 카드(TOP 7·관련 계산기·FAQ·허브 목록·최근)는 좌우 --pad-card.
8. 카드 사이 8px(이어서 계산), 같은 흐름 안 연속 카드 40~48px(BMI), 결과 카드 → 다음 카드 20px → 카드 사이.
9. 문단 사이 0~36px(지식 블록 0, 검토 안내 4, 사례 상자 32~36) → 문단 토큰.
10. 홈: 블록 사이를 카드 간격, 제목 있는 섹션 앞은 섹션 간격, "전체 15개" 누름 영역이 제목 줄을 키우던 것 정리(누름 영역 44px 유지).

두 칸 홈 끝 높이 차이(앞 지시 48px 이하): 최근 0개 46px, 3개 16px (1280·1440 같음).

## 이후 추가(2026-10-20)

- h1 머리 → 첫 섹션 규칙 추가(--gap-h1, ±4px). 머리 = h1 + 바로 붙은 부제·메타 줄. 실패 78 → 0.
- 바탕이 페이지와 같아 경계가 안 보이던 글 안 상자 10종 → 흰 바탕 + 1px 선. 판정도 "실제로 비치는 바탕색" 기준으로 바꿈.
- 검토 안내(글·계산기)는 카드가 아니라 한 줄(작은 아이콘 + --text-sub).
- 글 안 같은 종류 상자가 잇달아 오면(사례·단계·강조 등) 사이 간격 없이 구분선 있는 한 장으로 잇는다. 검사기는 틈 없이 이어 붙은 같은 종류를 카드 1장으로 센다(카드 사이 규칙도 같음).
- 블로그 글은 표본 20편이 아니라 184편 전부를 잰다(표본 밖에서 상자 문제가 나왔기 때문).
- **생성기 없는 페이지: 부동산 계산기 17개와 부동산 허브는 직접 고치는 페이지다.** 간격 규칙은 base.css 공용 규칙으로만 맞추고, 페이지 파일은 build_all.sh의 하단 목록·?v= 단계만 손댄다. dti·pyeong(main 판)은 승인된 예외.
- 측정 제외(승인): 광고 칸 안쪽, 입력 컨트롤, dti·pyeong.
