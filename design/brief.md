6. **신뢰 블록 카드**: 아이콘(shield-check) + 작성·검토일·기준·기관 2열 정의 목록. 한 줄 축소 금지.
7. **제휴 배너**: 아이콘 + 한 줄 카피 + 브랜드 아웃라인 버튼으로 정리해서 유지.
8. **헤더**: 흰 배경, 로고 + 아이콘 붙은 주요 카테고리 + 더보기 + 검색. **푸터**: `--text` 계열 짙은 배경으로 무게감, 카테고리 링크 4열 + 정책 링크.
9. **섹션 리듬**: 흰 카드 섹션만 반복하지 말 것. 히어로 밴드(틴트) → 계산 영역(카드) → 가이드(배경 없이 본문형) → 비교 타일 → FAQ(카드) → 짙은 푸터 순으로 배경을 바꾼다.

## 0. 지난 시안이 실패한 이유 (반복 금지)

1. **"shadcn 원본 그대로"를 문자 그대로 적용** → 흑백 와이어프레임처럼 보임. 브랜드 색이 0개. (참고: 사이트는 정적 HTML이라 shadcn은 쓰지 않는다. 스타일 원칙만 참고)
2. **모든 요소에 테두리** → 카드 안에 카드, 리스트 항목마다 박스. 관리자 템플릿 느낌.
3. **판정 색을 없앰** → "한도 이내/초과"의 의미가 안 읽힘. 게이지도 검정 막대.
4. **보조 텍스트가 너무 연하고 작음** → 기준일, 근거, 도움말이 안 보임. 신뢰 요소가 죽음.
5. **데스크톱 그리드 불균형** → 입력 카드가 짧아 아래가 텅 비고, 표·광고가 떠 있음.
6. **위계 없음** → 라벨, 값, 설명이 비슷한 크기/굵기. 결과 숫자만 큼.
7. **검정 CTA가 화면에서 가장 강함** → 결과보다 버튼이 먼저 보임.

## 2. 토큰 (이 값만 사용, 하드코딩 금지)

`/assets/ds/tokens.css` 에 아래를 그대로 정의한다. 다른 CSS·인라인 `<style>`에서는 이 변수만 참조한다.

```css
:root {
  /* 브랜드 */
  --brand: #0E6B57;          /* 딥그린: 신뢰 + 금융 */
  --brand-hover: #0A5745;
  --brand-tint: #E8F3EF;     /* 선택 상태, 활성 칩 배경 */

  /* 뉴트럴 (살짝 따뜻한 회색으로 통일) */
  --bg: #F6F6F3;             /* 페이지 배경 */
  --surface: #FFFFFF;        /* 카드 */
  --surface-sub: #FAFAF8;    /* 카드 안 보조 영역 */
  --line: #E6E5E0;           /* 구분선, 유일한 테두리 색 */
  --text: #17181A;           /* 본문, 값 */
  --text-sub: #575B62;       /* 라벨 보조, 도움말 (대비 4.5:1 이상) */
  --text-muted: #8C9097;     /* 정말 중요하지 않은 것만 */

  /* 판정 (색 + 아이콘 + 텍스트 항상 같이) */
  --ok: #12805C;   --ok-tint: #E7F5EE;
  --warn: #B26B00; --warn-tint: #FDF3E1;
  --bad: #C2362F;  --bad-tint: #FCEBEA;

  /* 형태 */
  --radius-sm: 8px;  --radius-md: 12px;  --radius-lg: 16px;
  --shadow-card: 0 1px 2px rgba(23,24,26,.04), 0 2px 8px rgba(23,24,26,.04);
}
```

| 페이지 제목 | 32/700 · 26/700 | letter-spacing -0.02em |
| 섹션 제목 | 20/700 · 18/700 | |
| 입력값 | 18/600 · 18/600 | 우측 정렬, `tabular-nums` |
| 라벨 | 15/600 · 15/600 | `--text` |
| 본문 | 16/400 · 16/400 | line-height 1.7 |

- 입력 필드 간: 20

## 3. 테두리/카드 규칙 (가장 중요)

- 카드는 **`--surface` + `--shadow-card`, 테두리 없음**. 페이지는 `--bg`.
- **카드 안에 테두리 박스 금지.** 그룹은 여백과 `--line` 구분선 1px로만 나눈다.
- 리스트(이어서 계산, 카테고리 목록)는 **항목별 박스 금지** → 한 카드 안에 구분선 리스트.
- 입력 필드만 예외: 1px `--line`, focus 시 2px `--brand` 링.
- 중첩 깊이 최대 1단계 (페이지 > 카드). 카드 > 카드 금지.

## 4. 화면별 지시

### 4-1. 계산기 상세 (DTI 기준, 모든 계산기 공통 템플릿)

**데스크톱 (≥1024px)** — max-width 1120, 12컬럼, gap 32
- 상단: 브레드크럼(13 `--text-sub`) → 제목 32 → 한 줄 설명 16 `--text-sub` → 메타 칩(`2026.4.1 시행 기준`, `10.12 검토`)은 `--surface-sub` 배경 + 13/500, 테두리 없음
- **왼쪽 7컬럼**: 입력 카드 → 설명 섹션(연소득별 한도 표) → 가이드 본문 → FAQ. 왼쪽이 길게 흐른다.
- **오른쪽 5컬럼 `position: sticky; top: 88px`**: 결과 카드 → 이어서 계산 → 근거/검토 정보.
- 광고(300x250)는 오른쪽 sticky 영역 **밖**, 왼쪽 콘텐츠 흐름 중간(표 아래)에 높이 고정으로 배치. 빈 박스로 크게 보이지 않게 `--surface-sub` + 작은 "광고" 라벨.
- 입력 카드: 2열 그리드 유지하되 라벨-필드-도움말 간격 일정하게 (8 / 6).

**결과 카드**
- 라벨 "내 DTI" 15/600 → 숫자 52 → 판정 pill(아이콘 + "한도 이내", 배경 `--ok-tint`, 글자 `--ok`)을 숫자 옆이나 바로 아래.
- 게이지: 높이 8, 둥근 끝, 채움색 = 판정색, 한도 지점에 세로 tick + "한도 40%" 라벨(13 `--text-sub`).
- 상세 3줄: 라벨 `--text-sub` 15 / 값 `--text` 16/600 우측 정렬, 구분선만.
- 버튼: 주 버튼 1개(`--brand`, "DSR도 계산 →"), 보조는 텍스트 버튼("결과 복사", 아이콘 포함). 검정 버튼 금지.
- 값이 바뀔 때 숫자에 200ms 페이드 정도만. 그 외 모션 없음.

**모바일 (<768px)**
- 순서: 제목 → 입력 카드 → 결과 카드 → 이어서 계산 → 표 → 광고 → 가이드.
- 결과 카드를 지나 스크롤하면 **하단 고정 요약 바**(높이 56, `--surface`, 상단 그림자): "DTI 34.0% · 한도 이내" + 판정색 점. 탭하면 결과 카드로 스크롤.
- 입력 필드 높이 52, 터치 영역 최소 44.
- 상단 카테고리 칩: 가로 스크롤 + 우측 페이드 그라데이션 마스크(장식 아님, 스크롤 힌트). 활성 칩 `--brand-tint` 배경 + `--brand` 글자.

### 4-2. 카테고리 페이지
- 제목 + 설명 → 세그먼트 탭(전체/살 때/대출/보유/팔 때) 활성 = `--brand` 밑줄 2px.
- 그룹별 섹션 제목(15/700) 아래 **한 카드 안 구분선 리스트**. 항목: 이름 16/600 + 설명 13 `--text-sub` + 우측 chevron(`--text-muted`).
- "인기" 배지: `--brand-tint` 배경 + `--brand` 12/600. 테두리 금지.

### 4-3. 홈
- 상단: "무엇을 계산할까요?" 26/700 + 큰 검색창(높이 56, `--surface`, 그림자) + 추천 검색어 칩.
- "이번 달 많이 찾는 계산기": 순위 숫자를 `--brand` 18/700 tabular로 강조, 한 카드 구분선 리스트.
- 카테고리 그리드: 2열(모바일)/3열(데스크톱) 타일, 테두리 없음, 아이콘 대신 카테고리 대표 색 점 금지 → **카테고리명 + 개수 + 대표 계산기 2개 텍스트**로 구성(정보형 타일).
- "최근 기준이 바뀐 계산기": 날짜를 좌측 고정폭 tabular로.

### 4-4. 헤더/푸터
- 헤더: 흰 배경 + 하단 `--line` 1px, 높이 64(모바일 56). 로고 아이콘의 보라색 제거 → `--brand` 사각 + 흰 "J".
- 데스크톱 내비 활성 항목: `--brand` 글자 + 하단 2px 바. 점(•) 표시 금지.
- 카테고리별 색은 v2 보정 2번 규칙대로 아이콘 타일·칩에만 사용. 버튼·판정은 `--brand` 하나.
- **좌측 사이드바 제거.** 카테고리 이동은 헤더 내비 + 페이지 상단 브레드크럼으로 충분하다. 12개가 헤더에 다 안 들어가면 주요 6개 + "더보기" 드롭다운.
- 이모지는 전부 라인 아이콘으로 1:1 교체(삭제 아님).
- 푸터: `--bg` 배경, 13 `--text-sub`.

## 8. 보고 형식
스크린샷 2장 + 체크리스트 결과 + 남은 이슈만. 변경 내역 나열 금지.

### 시안 검수 메모 (구현 시 시안보다 이 메모 우선)
- B2 결과 바: 판정·숫자는 **필수 입력이 모두 찼을 때만** 표시. 하나라도 비면 B2c 문구("값을 모두 입력하면 DTI가 계산됩니다" + "N개 남음"). B2b 시안은 원리금이 빈 채 34.0%가 떠 있는데 이는 시안 오류.
- B2b 키보드 위 결과 바 오른쪽 버튼 문구는 "완료"(시안 글자 깨짐).
- 하단 탭바 활성: 홈=홈, 계산기·카테고리 페이지=카테고리, 블로그=블로그, 최근=최근. (B2 시안의 "홈" 활성은 오류)
- A3 카테고리 이름 "이직·연봉" → 실제 이름 "이직/연봉". 모바일 푸터는 A4 데스크톱 푸터를 1열로 쌓아 사용.
- B3 값 자동 입력: 안내 띠 버튼 문구는 "지우기"(시안 "자우기"는 오타). 가져온 값 칸의 "가져옴" 배지는 사용자가 값을 수정하면 사라짐. "지우기"는 가져온 값만 비움.
- 결과 대기(고스트) 카드의 숫자는 "0.0%" 금지 — 회색 "--%" 로 표시(0.0%는 실제 결과로 오해됨).
