# 전세자금대출(버팀목) 계산기 빌드 플랜

- **slug**: `jeonse-loan` (부동산/realestate 19번째)
- **name**: 전세자금대출 / display "전세자금대출(버팀목) 계산기"
- **icon**: 🏘️
- **트래픽**: 0.16x (앵커 중개수수료 대비). realestate 잔여 마지막 ④티어. → 부동산 라인 완성.
- **검증**: 2026-06-19, 48셀+요건 **적대적 재검증 통과**(myhome.go.kr·nhuf 교차, 보간 의혹 기각)

## 입력
1. 모드 토글: [버팀목(일반)] / [신생아 특례]
2. 임차보증금 (만원)
3. 부부합산 연소득 (만원)
4. 지역 seg: [수도권] / [비수도권] → 보증금상한·한도cap·금리(-0.2%p) 분기
5. 유형 select(모드별): 일반=일반/신혼/2자녀, 신생아=외벌이·단독/맞벌이
6. 희망 대출액 (만원, 선택)

## 유형 파라미터
### 버팀목 일반 [소득cap, 보증금상한_수도권, _지방, 한도_수도권, _지방, 대출비율%]
- 일반:   5000, 30000, 20000, 12000, 8000, **70**
- 신혼:   7500, 40000, 30000, 25000, 16000, **80**
- 2자녀:  6000, 40000, 30000, 25000, 16000, **80**

### 신생아 특례 버팀목 [소득cap, 보증금상한_수도권, _지방, 한도(호당), 대출비율%]
- 외벌이·단독: 13000, 50000, 40000, 24000, 80
- 맞벌이:      20000, 50000, 40000, 24000, 80
- (호당한도 24000=6.27 축소, 이전 30000. 지역무관)

## 금리표 (수도권 기준, 비수도권 -0.2%p, 하한 1.0%)

- ≤4000: 1.60 1.70 1.80 1.90

## 출력
- 소득요건 / 보증금요건 판정
- 적용 대출비율
- 최대 대출한도 = min(한도cap_지역, floor(보증금 × 대출비율%))
- 적용 기본금리 = matrix[소득밴드][보증금구간] − (비수도권 0.2), floor 1.0. 우대 전.
  - ⚠️금리조회 소득은 유형 소득cap으로 캡(외벌이 맞벌이밴드 누출 방지, didimdol과 동일)
- 월 이자 (만기일시·이자만) = 대출액 × 금리 / 1200
- 연 이자
