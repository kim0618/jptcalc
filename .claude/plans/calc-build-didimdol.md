## 핵심 검증 사항 (메모리 가정 정정)
- ⚠️ 신생아 특례 소득 2.5억 상향 = **백지화(무산)**. 현행 1.3억 / 맞벌이 2억.
- ⚠️ 6.27 대책(2025.6.28~)으로 한도 축소: 신생아디딤돌 5억→**4억**, 일반디딤돌 2.5억→**2억**, 생애최초 3억→**2.4억**, 신혼·2자녀 4억→**3.2억**.
- 순자산 요건 = 디딤돌 5.11억(연 변경 변수, 안내만).

1. 모드 토글(seg): [일반 디딤돌] / [신생아 특례]
2. 주택가격 (만원)
3. 부부합산 연소득 (만원)
4. 대출만기 select: 10 / 15 / 20 / 30년
5. 유형 select (모드별 옵션 교체):
   - 일반: 일반 / 생애최초 / 신혼가구 / 2자녀이상

## 출력
- 소득 요건 판정 (소득 ≤ 소득cap)
- 주택가격 요건 판정 (주택가 ≤ 주택가cap)
- 적용 LTV
- 대출한도 = min(한도cap, floor(주택가 × LTV%))  ※ DTI 60% 별도, 안내
- 적용 기본금리 (matrix[소득밴드][만기])
- 월 상환액 (원리금균등) = L·mr·(1+mr)^n / ((1+mr)^n−1), mr=금리/1200, n=만기×12 / L=희망액||한도
- 총 이자 / 총 상환액
