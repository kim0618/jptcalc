## 0. 웹 검증 완료 (2026-06-19, 2소스+)
- **정의(근로기준법 제26조)**: 사용자가 30일 전 예고 없이 해고 시 30일분 이상의 통상임금 지급.
- **⚠️ 1일 통상임금 산정 = 고용노동부 행정해석 확정**: 통상시급(월÷209) × 8시간 = 1일 통상임금, × 30일.
  - **"월급제 근로자의 30일분 통상임금은 한 달 임금이 아니다"** (행정해석 명시). 웹 간이예시 ÷30은 오류.
  - 검증 예시: 월 250만원 → 시급 11,961.72 → 일급 95,693.76 → ×30 = **2,870,813원**.
  - 우리 프로젝트 기존 컨벤션(annual-leave-pay·ordinary-wage의 (월÷209)×8)과 일치.
- **예외(제26조 단서, 지급의무 없음)**: ①계속근로 3개월 미만 ②천재사변·부득이한 사유로 사업계속 불가 ③근로자 고의로 막대한 지장/재산손해. → ①은 계산 게이트, ②③은 안내.
- 출처: 근로기준법 제26조, easylaw.go.kr, 고용노동부 행정해석.

## 2. 계산 로직
입력:
1. 통상시급 (mode 토글: 통상시급 직접입력 원 / 월 통상임금 환산 만원→÷209)
2. 계속근로기간 (토글: 3개월 이상 / 3개월 미만)

계산:
- 통상시급 = 직접 or 월÷209
- 1일 통상임금 = 통상시급 × 8
- 해고예고수당 = 1일 통상임금 × 30
- 3개월 미만 → 0 + "지급 대상 아님" 안내

출력: 통상시급 / 1일 통상임금 / **해고예고수당(highlight)** / 예외 배지.
