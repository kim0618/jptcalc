# 평균임금 계산기 개발 계획 (salary)

> 기존 추가(셋업0) ④티어. 트래픽 0.3x(salary 마지널 중 최대). 노무 distinct 키워드 "평균임금 계산기 / 평균임금 산정".
> ⚠️ 자기잠식 리스크: 퇴직금(severance) 계산기가 1일 평균임금을 내부 계산함. → 아래 차별화 설계로 회피.

## 0. 웹 검증 완료 (2026-06-19, 2소스+)
- **정의(근로기준법 제2조⑥)**: 평균임금 = 산정사유 발생일 이전 3개월간 지급 임금총액 ÷ 그 기간 총일수.
- **산입**: 기본급+수당 3개월분 + 연간상여금×3/12 + 연차수당×3/12.
- **통상임금 최저보장(제2조②)**: 평균임금 < 통상임금이면 통상임금을 평균임금으로.
- **제외기간**: 산재요양·육아휴직·군복무 등은 기간·임금 모두 제외(안내만, 입력단순화).
- **활용처**: 휴업수당 70%(제46조)·산재 휴업급여 70%(저소득 90%)·퇴직금 30일분·실업급여·감급제재.
- 출처: easylaw.go.kr(평균임금/휴업급여), nodong.org, 고용노동부.

## 1. 차별화 설계 (퇴직금과 자기잠식 회피 - 핵심)
| 구분 | 퇴직금(severance) | 평균임금(신규) |
|---|---|---|
| 입력 | 입사일·퇴직일(재직기간) + 3개월급여 | **재직기간 불필요**. 사유발생일 + 3개월급여 |
| 주 출력 | 퇴직금 총액 | **1일 평균임금** 자체 + 다목적 활용처 |
| 용도 | 퇴직 1개 | 휴업수당·산재·퇴직금·실업급여 **다목적** |
| 통상임금 비교 | 없음 | **최저보장 비교 내장** |

→ 평균임금 계산기는 "1일 평균임금"을 정확히 뽑고, **활용처별 환산표**(휴업수당·산재·퇴직금 30일분)를 제공. 퇴직금 총액은 안 냄 → severance를 "관련 계산기"로 링크(상호보완, 중복X).

## 3. 계산 로직
입력:
1. 산정사유 발생일 (년/월/일) → 이전 3개월 총일수 자동(89~92일, severance 방식 재사용)
2. 직전 3개월 월평균 임금 (만원)
3. 연간 상여금 (만원, 3/12 산입)
4. 연간 연차수당 (만원, 3/12 산입)
5. (선택) 1일 통상임금 (원) — 최저보장 비교용, 미입력 시 스킵

계산:
- 3개월 임금총액 = 월평균×3 + 상여×3/12 + 연차수당×3/12 (만원→원)
- 1일 평균임금 = 임금총액 ÷ 3개월 총일수
- 최저보장: 통상임금 입력 시 `적용 평균임금 = max(1일 평균임금, 1일 통상임금)`, 통상임금이 크면 배지 표시
- 활용처 환산(적용 평균임금 기준):
  - 휴업수당 1일 = ×0.70
  - 산재 휴업급여 1일 = ×0.70
  - 30일분(퇴직금 1년치 기준) = ×30
  - 1개월(평균임금 월액) = ×30

출력: 3개월 총일수 / 3개월 임금총액 / **1일 평균임금**(highlight) / 최저보장 배지 / 활용처 환산 4행.
