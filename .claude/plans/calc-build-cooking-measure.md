## 왜 만드나 (근거)
- 블로그 1위 글 `cooking-measurement-guide`가 주 42명(10/26~11/01) 유입인데 계산기 클릭 5%(사이트 평균 13%, 계산형 글 30~50%). 연결된 unit-converter에 컵·큰술·작은술·재료별 g이 없다(단위 목록 확인) = 독자 의도에 맞는 계산기 부재.
- 네이버 SERP(계량 변환기·1컵 몇 그램·밀가루 1컵 그램·계량스푼 변환) 상위가 miniwebtool·calnexa·dynamiclabs·easycalc 등 소형 계산기 사이트 = 진입 가능 슬롯. '계량스푼 변환'엔 jptcalc 블로그 이미 노출.
- 기대치(가정, 실측 아님): 블로그 경유 주 10명 안팎 + 검색 유입은 색인 후 4주 관측.

## 기능
1. **부피 단위 변환**: 숫자 + 단위 하나 입력 → 나머지 전부 표시
   - 작은술 5ml / 큰술 15ml / 컵(한국) 200ml / 컵(미국) 약 236.6ml / ml / L
   - 참고 대체도구(근사, "약"으로 표시): 종이컵 약 180ml, 소주잔 약 50ml. 밥숟가락은 20~25ml 범위라 단일값 변환에서 제외하고 안내 문구로만.
2. **재료별 무게(g) 환산**: 재료 선택 + 양(단위) → g, 반대로 g → 컵·큰술
   - 계산 = 부피(ml) × 밀도(g/ml). 밀도는 아래 데이터 출처에서만 가져온다.
   - 결과에 "계량 방법(가루를 눌러 담는지·깎는지)에 따라 ±10% 안팎 달라짐" 고정 안내.
3. **미국 레시피 모드**: 컵 기준을 한국 200ml / 미국 236.6ml 토글(블로그 시나리오1 "미국 1컵 밀가루를 한국 컵에 담으면 15% 부족" 그대로 계산되게).

## 🔴 데이터 출처 (착수 1단계, 이게 없으면 만들지 않는다)
- **블로그 표는 출처가 없고 자체 모순이 있다**: 설탕 1컵(200ml)=200g(1.0g/ml)인데 같은 표 1큰술(15ml)=12g(0.8g/ml). 일반 백설탕 밀도(약 0.85g/ml)면 1컵 약 170g. → 계산기 데이터로 쓰지 않고, 같은 작업에서 블로그 표도 원문 값으로 정정한다.
- **1순위**: USDA FoodData Central(SR Legacy)의 household measure("1 cup = N g", "1 tbsp = N g") → 미국 컵 236.6ml·큰술 14.8ml로 나눠 밀도 산출. 공개·인용 가능, 재료별 수치가 명시돼 있음.
- **2순위(한국 재료)**: 간장·고추장·된장·고춧가루·참기름·물엿 등은 농촌진흥청 국립농업과학원·식약처 공개 자료(계량 단위·눈대중량)에서 찾는다. **원문을 못 찾은 재료는 목록에서 뺀다**(추정값 금지, [[fabricated_reference_table]]).
- **한국 1컵=200ml 기준** 자체도 원문 출처를 확보해 data-points에 등재(블로그는 "한국 조리법 표준화 기준"이라고만 씀).
- 등재: `data-points.md` §72(신규) - 재료·밀도·출처 URL·확인일.

## 2026-11-02 가치 검증 결과: 보류 권고
- 계량 글 유입은 진짜·성장 중(주 6→20→39→51, 13주, 모바일 90%·네이버 검색, 평균 약 60초).
- 그러나 ①같은 성격의 unit-converter는 90일 PV 44(discount 21) = 변환형 계산기는 이 사이트에서 검색 유입을 거의 못 받음 ②네이버 SERP: '1컵 몇 그램'은 상단 AI 브리핑이 답을 바로 줌, '계량 변환기'는 1위 toolpedia의 재료별 g 표가 검색 결과에 스니펫으로 노출, '밀가루 1컵 그램'은 수천만 인용 레시피 블로거(네이버 메이트) 블록 = 클릭 없이 답이 끝나거나 기존 강자가 차지 ③과거 신규 계산기 예측은 체계적으로 과대(노란우산 90일 75, 장병내일적금 32).
- 사이트 내부 효과만 계산: 주 51명 × 25% = 주 약 13PV(월 약 55PV), 수익 기준 월 100원 안팎(현 월 PV 약 5,600에 수익 1만원 미만 비례).
- **대신 할 것**: 계량 글 재료 표를 원문 값으로 정정·확장(설탕 1컵 200g 의심, 출처 없음). 블로그 1위 글의 숫자 정확도가 계산기보다 가치가 큼.
- **재검토 조건**: 계량 글이 주 100명 이상으로 크거나, 정정 후 글 내부 단위변환기 클릭이 주 10명 이상 나오면 다시 판단.
