인프라 비용 항목별 계산 방법

AI 스타트업 인프라 예산은 서비스 단계별로 비용 구조가 크게 달라집니다. 초기에는 LLM API 비용이 지배적이지만, 월간 활성 사용자(MAU) 1만 명을 넘어서면 클라우드 서버와 DB 비용이 빠르게 늘어납니다. 항목별로 나눠 입력하면 어떤 항목이 예산의 발목을 잡는지 한눈에 파악할 수 있습니다.

  • LLM API 비용. 월간 예상 API 호출 수와 평균 토큰 수로 계산합니다. GPT-5.4 기준 input $2.50/1M, output $15/1M 토큰 (2026년 6월 기준). 캐싱과 프롬프트 압축으로 30~50% 절감이 가능합니다.
  • 클라우드 서버 비용. 애플리케이션 서버 EC2/GCE 인스턴스 기준으로 입력합니다. 초기에는 $50~200/월이지만 오토스케일링 시 급등할 수 있습니다.
  • DB 비용. RDS(MySQL/PostgreSQL)는 db.t3.medium 기준 약 $50~80/월. 데이터 증가에 따라 스토리지 비용도 별도 계산합니다.
  • 모니터링 비용. Datadog 기준 호스트당 $23/월, CloudWatch는 메트릭당 $0.30/월. 규모가 커질수록 모니터링 비용이 빠르게 늘어납니다.

실제 계산 예시

예시 1 - 초기 단계 AI 챗봇 스타트업 (월 사용자 1,000명)

GPT-5.4 기반 챗봇 서비스. 사용자당 평균 10회 대화, 대화당 평균 2,000 토큰(input+output) 소모.

  • LLM API: 1,000명 × 10회 × 2,000토큰 = 2,000만 토큰/월 → $50/월
  • 클라우드 서버 (EC2 t3.medium × 1): $30/월
  • DB (RDS t3.micro): $25/월
  • 모니터링 (CloudWatch 기본): $10/월
  • 총 월 인프라 비용: 약 $115/월 (약 17만원). 권장 예비비 15% 포함 시 $132/월

예시 2 - 성장 단계 B2B SaaS (월 사용자 10,000명)

동일 챗봇 서비스가 10배 성장한 경우. 사용자당 대화 패턴은 동일하지만 안정성을 위해 서버 이중화가 필요합니다.

  • LLM API: 10,000명 × 10회 × 2,000토큰 = 2억 토큰/월 → $500/월
  • 클라우드 서버 (EC2 c5.xlarge × 2, 이중화): $300/월
  • DB (RDS db.t3.large): $150/월
  • CDN/네트워크: $50/월, 모니터링 (Datadog 2호스트): $60/월
  • 총 월 인프라 비용: 약 $1,060/월 (약 154만원). 사용자 10배 성장에 비용은 약 9배 증가

이것만은 확인하세요

AI 스타트업 인프라 예산 수립 시 자주 빠뜨리는 항목과 주의할 점을 정리했습니다.

  • 예비비(버퍼) 반드시 포함. 트래픽 급증, 버그로 인한 API 과다 호출, 장애 복구 비용 등 예상치 못한 지출이 자주 발생합니다. 계산기가 자동으로 표시하는 15% 예비비를 예산에 포함하세요.
  • LLM API 캐싱 적극 활용. 동일 프롬프트를 반복 사용하는 경우 API 캐싱으로 30~50% 절감이 가능합니다. Claude Sonnet 4.6의 프롬프트 캐싱은 cached input $0.30/1M으로 일반 input($3/1M)의 10% 수준입니다.
  • 클라우드 가격 수시 변경. 클라우드 서비스 가격은 수시로 변경됩니다. 계획 수립 후 계약 직전에 각 벤더 공식 가격 페이지에서 최신 단가를 재확인하세요.

자주 묻는 질문

트래픽이 늘면 비용이 비례해서 늘어나나요?

대부분의 클라우드 비용은 비선형적으로 증가합니다. 특히 LLM API 비용은 사용량에 정비례하지만, 서버와 DB는 스케일링 방식에 따라 다릅니다.

모니터링 비용도 포함해야 하나요?

네. Datadog, CloudWatch 등 모니터링 도구 비용은 인프라 규모에 따라 월 수백 달러에 달할 수 있어 빠뜨리면 예산 차이가 큽니다.

초기 단계에서 가장 큰 비용 항목은?

대부분 LLM API 비용이 가장 큽니다. 서비스 성장 후에는 GPU 서버와 DB 비용이 급격히 늘어나는 경우가 많습니다.

LLM API를 직접 서버로 교체하면 비용이 절감되나요?

규모에 따라 다릅니다. 월 LLM API 비용이 $2,000 이상인 경우 자체 오픈소스 모델(Llama, Mistral 등) 호스팅을 검토할 수 있습니다. A100 GPU 서버 1대 임대 비용($2,000~3,000/월)과 API 비용을 비교해 손익분기점을 계산해보세요. 단, 모델 품질 차이와 운영 인력 비용도 함께 고려해야 합니다.

무료 티어나 스타트업 크레딧을 활용하면 얼마나 절감되나요?

AWS Activate는 최대 $10만 크레딧, GCP for Startups는 최대 $20만 크레딧을 지원합니다. Anthropic, OpenAI도 초기 스타트업 대상 크레딧 프로그램을 운영하고 있습니다. 인프라 초기 12~24개월 동안 크레딧을 활용하면 실제 현금 지출을 크게 줄일 수 있으므로 각 공식 스타트업 프로그램 페이지에서 신청 조건을 확인해보세요.
